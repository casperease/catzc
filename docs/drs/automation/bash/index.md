# Bash automation records

The records here govern the repository's Bash code, which is test artifacts only — black-box tests of the engine that reach catzc through
the `cats` dispatcher and never ship; see [bash-test-artifacts](bash-test-artifacts.md). bash as one of the three execution engines is
governed one level up, by [execution-engines](../execution-engines.md). Cross-cutting, language-agnostic platform rules live directly under
`automation/`; the full code↔DRS registry is the DRS index at the root of `docs/drs/`.
