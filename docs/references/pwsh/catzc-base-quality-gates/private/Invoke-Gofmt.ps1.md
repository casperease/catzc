# pwsh/Catzc.Base.QualityGates/private/Invoke-Gofmt.ps1

The comments of the file that outgrew one line, one section per comment, verbatim. A section names the code line its comment sat above
(Export-Comments), and Build-CommentView puts every comment back there for reading.

## help

### synopsis

The gofmt formatter engine: formats the given Go files with the managed go's gofmt and returns the files it changed.

### description

One Format-Code engine adapter
([PDR-CONFIG-NEWINSTANCEISCONFIGCHANGE](../../../../drs/principles/configure-not-program.md#rule-pdr-config-newinstanceisconfigchange)).
gofmt is the gofmt beside the managed go at the tools.yml pin ([ADR-AUTO-GO](../../../../drs/automation/go/go-test-artifacts.md)), never
whichever gofmt is first on PATH; a missing or off-pin go throws, naming Install-Go. `gofmt -l` names the files that differ; without
-DryRun, `gofmt -w` rewrites exactly those. go.mod and go.work are not Go files: New-GoWorkspace and go itself write them.

### parameter `File`

Absolute paths of the .go files to format.

### parameter `DryRun`

List the files gofmt would change without writing them.

### outputs

`[string[]]` Absolute paths of the files changed (or, under -DryRun, that would change).
