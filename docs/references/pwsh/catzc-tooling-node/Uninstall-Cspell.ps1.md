# pwsh/Tooling.Node/Uninstall-Cspell.ps1

The uninstaller of cspell, the counterpart of `Install-Cspell`.

## help

### synopsis

Uninstalls cspell (the global npm package).

### description

Idempotent — skips if cspell or npm is not present (nothing to uninstall).

### example 1

```powershell
Uninstall-Cspell
```
