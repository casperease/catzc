## help

### synopsis

Packs a Catzc build into a NuGet package (.nupkg) for a local-path Install-PSResource.

### description

The package delivery shape
([ADR-AUTO-BUNDLE-TWOARTIFACTINSTALL](../../../../drs/automation/platform-bundle.md#rule-adr-auto-bundle-twoartifactinstall)). The build
folder is already an installable module — its Catzc.psd1 carries the version, GUID and package metadata, its Catzc.psm1 loads the platform,
and the vendored dependencies ride inside its .vendor/ — so the build folder itself is compressed, as is, with Compress-PSResource into
`<DestinationPath>/Catzc.<version>.nupkg` (pack only, no publish). A client registers the destination folder as a PSResource repository and
runs Install-PSResource Catzc. Publishing beyond the local disk is the release workflow's act
([ADR-GH-RELEASE](../../../../drs/github/github-release.md)).

### parameter `Source`

The build root (Build-Modules' BuildRoot — the `Catzc/<version>/` folder).

### parameter `DestinationPath`

The directory the .nupkg is written into.

### outputs

`[pscustomobject]` with NuPkg, Version (from Catzc.psd1), Manifest (the build's Catzc.psd1), ModulePath (the build root), and FunctionCount
(the public functions the build's modules export).
