# pwsh/Catzc.Base.Slides/private/Get-DiagramProofFinding.ps1

The comments of the file that outgrew one line, one section per comment, verbatim. A section names the code line its comment sat above
(Export-Comments), and Build-CommentView puts every comment back there for reading.

## help

### synopsis

Checks that an action diagram's about.proves file exists and holds the diagram's action and every effect's proves, verbatim.

### description

An action diagram draws accosted commands, and the accosted file named by about.proves runs them, so the picture never says what the proof
does not run. The file is read by Get-AccostedFile, the one reader
([ADR-AUTO-ACCOSTED-ONEREADER](../../../../drs/automation/accosted-language.md#rule-adr-auto-accosted-onereader)), and each command the
diagram draws (the action's call or calls, and every effects[].proves) is read by the reader's own command type and must equal a command of
the file in name and arguments. A diagram whose about.lens is not action is a band diagram, and the check is inert for it.

### parameter `Stem`

The diagram's stem, repository-relative, for the finding text.

### parameter `Text`

The diagram's declaration, the yml text.

### parameter `RepositoryRoot`

The root about.proves resolves against.

### outputs

`[string[]]` One finding per fault; nothing when the diagram is a band diagram or proven.
