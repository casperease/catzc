# pwsh/Base.GeneratedFiles/types/GeneratedWriterDue.cs

The result of `Get-GeneratedWriterDue` for one writer: what its writer row's inputs and outputs say about it now.

## Properties

- **`Name`** — the writer.
- **`Due`** — whether it is due: an output named without a wildcard is missing, or its input stamp changed since its last run.
