# pwsh/Tooling.Node/Uninstall-Markdownlint.ps1

The uninstaller of markdownlint-cli2, the counterpart of `Install-Markdownlint`.

## help

### synopsis

Uninstalls markdownlint-cli2 (the global npm package).

### description

Idempotent — skips if markdownlint-cli2 or npm is not present (nothing to uninstall).

### example 1

```powershell
Uninstall-Markdownlint
```
