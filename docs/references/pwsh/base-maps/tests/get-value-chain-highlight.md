# pwsh/Base.Maps/tests/Get-ValueChainHighlight.Tests.ps1

The tests of `Get-ValueChainHighlight`, which lights the value-chain map cells of ADR codes
([DDR-TRACK-LITCELL](../../../../drs/design/tracks.md#rule-ddr-track-litcell),
[ADR-REPO-VALUECHAIN-MAP][r1]). The logic tests mock the map with widget and
gadget fixtures ([ADR-AUTO-TEST-DISTINCTFIXTURES](../../../../drs/automation/test-automation.md#rule-adr-auto-test-distinctfixtures)).
