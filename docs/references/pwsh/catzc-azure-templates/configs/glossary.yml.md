# pwsh/Azure.Templates/configs/glossary.yml

The glossary source of the Azure.Templates module: the vocabulary of the Bicep template configuration this module builds and deploys
([ADR-REPO-VOCAB](../../../../drs/repository/controlled-vocabulary.md)). `Test-Glossary` checks it.

## Defaults

Every option is defaulted: all five checks, the whole repository and every text surface
([ADR-REPO-VOCAB-GLOSSARYSOURCE](../../../../drs/repository/controlled-vocabulary.md#rule-adr-repo-vocab-glossarysource)). The file lists
only the concepts.
