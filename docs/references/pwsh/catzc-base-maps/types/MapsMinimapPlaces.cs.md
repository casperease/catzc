# pwsh/Base.Maps/types/MapsMinimapPlaces.cs

The budget of the "Where does it live?" minimap and the order its place groups take the rows
([ADR-AUTO-IDIOM-PLACENORMALFORM](../../../../drs/automation/idiomatic-names.md#rule-adr-auto-idiom-placenormalform)): the number of rows
and of counter rows, the characters a row may hold, and the separators, prefix and root marker the row form uses. `PlaceRows` reads it.
