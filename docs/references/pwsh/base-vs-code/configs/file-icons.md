# pwsh/Base.VSCode/configs/file-icons.yml

The registry of the cats file icon theme, rendered by `New-VsCodeFileIconTheme` into the `catzc-file-icons` extension.

## Icons

The theme has one icon per file type in the tree, each a recoloured lamp glyph or a generated label. A file no icon marks is one dot, in its
default colour on `FileIconsConfig`. A folder takes no icon; the Explorer's chevrons mark it.
