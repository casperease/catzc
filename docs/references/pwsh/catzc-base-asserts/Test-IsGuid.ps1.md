# pwsh/Base.Asserts/Test-IsGuid.ps1

The query form that answers whether a string is a valid GUID; `Assert-IsGuid` is its throwing form.

## help

### synopsis

Tests whether a string is a valid GUID.

### parameter `ObjectGuid`

The string to validate as a GUID.

### example 1

```powershell
Test-IsGuid '15000000-1700-a000-601d-000000000000'
```
