# docs/references/contracts/catzc.md

`The catzc contracts`

The contract assets of the `catzc` root: one table per version folder, then the notes of its assets.

`Build-ContractReference` writes this page from `contracts/catzc/`: edit an asset, its description or its header comment, never this page.

Each note is the asset's own: the `description` of a command contract, the `$comment` of a schema, or the leading `#` lines of another YAML
asset.

A presence asset, a text fragment, and a JSON fragment or sample payload carry no note: a comment would change what they pin.

A command contract's signature is the call interface its contract language states, as `Get-CommandContract` reads it; every other kind has
none.

Layout, kinds, and directions: [api-contracts](../../drs/repository/api-contracts.md); command contracts:
[command-contracts](../../drs/repository/command-contracts.md).
