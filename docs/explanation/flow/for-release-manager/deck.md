## About

The deck is the visual of the research and thesis records read through one role: the Release Manager, who serves the signatures and watches the ladder. Every slide is one fact with the code of the record it rests on, a lead that says what the fact means for that role, and one diagram of the catalogue, reduced, from the seeded pool. The records are read in the [index](../../../drs/index.md).
