# A day in cats, in twelve facts

## Sections

- read-the-index-first: One working day, from the first probe to the last full test run, each step on a record.

## About

The deck is the visual of an ordinary session with cats: a person starts a session, reads the index, edits one file at a time, runs the gate that covers it, lands a render at its source position, and ends with the one full test run in a fresh process. Every step is a fact with its record code. Each slide shows one diagram of the catalogue, reduced.
