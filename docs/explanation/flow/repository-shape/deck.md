# The shape of the repository, in fourteen facts

## Sections

- kinds-are-tracks: Tracks, folders, heads, links and words: what the tree is made of and what keeps it in shape.

## About

The deck is the visual of the repository records on structure: the tracks a file lives in ([tracks](../../../drs/design/tracks.md)), the stable folders and file names ([conventional-folders](../../../drs/repository/conventional-folders.md)), the generated file heads, the two kinds of link ([links](../../../drs/repository/links.md)) and the controlled vocabulary ([controlled-vocabulary](../../../drs/repository/controlled-vocabulary.md)). Each slide is one fact with its record code and one diagram of the catalogue, reduced.
