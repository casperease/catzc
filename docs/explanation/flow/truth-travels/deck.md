# How one truth travels down into code and back up, seen from quality control

## Sections

- one-truth: One concept at the top of the records, followed down into implementation and back up, as the gates see it.

## About

The deck is the visual of one journey through the decision records: it starts at the thesis,
[one-source-of-truth](../../../drs/thesis/one-source-of-truth.md), descends through the principles, the flow and the automation records
into the PowerShell implementation, climbs back into the records where a gate's rule is written, descends once more into the code the gate
checks, climbs again through design, flow and principle to the thesis's stores, and ends on a verification slide. Every slide is one fact
with the code of the record it rests on, and shows one diagram of the catalogue, reduced, picked from a seeded random pool of thirty.
Quality control is the thread: at every level the slide says what checks the fact, a gate in code or a record under review.
