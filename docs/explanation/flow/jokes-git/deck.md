# Ten git jokes that are also true

## Sections

- user-runs-git-pete: Every slide is a joke about git in cats, and every joke rests on a record.

## About

The deck is the visual of the git records told as jokes: the sync point, the rebase, the squash, the user at the keyboard. The same cast wanders through. Each slide names its record and shows one diagram of the catalogue, reduced.
