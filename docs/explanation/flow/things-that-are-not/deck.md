# Twelve things cats is not

## Sections

- not-a-monolith: Each slide is one thing the records rule out, and the code that rules it out.

## About

The deck is the visual of the negative space of the decision records: what the repository refuses to be. Each slide names one thing that is not allowed, the record that rules it out, and the one living way instead. Each slide shows one diagram of the catalogue, reduced.
