## About

The deck is the visual of the Azure DevOps, GitHub and Azure records read through one role: the CTO, who owns the delivery system and its cost. Every slide is one fact with the code of the record it rests on, a lead that says what the fact means for that role, and one diagram of the catalogue, reduced, from the seeded pool. The records are read in the [index](../../../drs/index.md).
