# There is one way to do each thing, and variability is reduced on purpose

## Eyebrow

4 / 12 · fact · PDR-REDUCEVAR

## Lead

A second way to resolve, name or load something is a defect, not a convenience. Fewer variants mean fewer places a fault can hide and one
place a gate must look.
