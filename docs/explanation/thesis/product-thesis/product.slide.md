# Cats is one command surface for delivery as code

## Eyebrow

What cats is

## Body

Cats is tooling, a cmdlet and CLI tool, that controls every aspect of software and infrastructure delivery as code: delivery, DevOps,
infrastructure, architecture and test constructs, through one command surface.

Its purpose is to simplify delivery. Every other rule in the system serves that purpose, and the thesis says how cats achieves it.

## Notes

The product in two sentences. A rule that does not serve simpler delivery does not belong in the system.
