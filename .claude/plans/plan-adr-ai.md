# ADR-AI: the contract every agent and skill reads first

Written 2026-10-16 at the user's ask, as docs/adr/repository/ai-agent-contract.md: 13 rules, under 100 lines, no links, each rule one line
to act on plus the why, with ADR codes as pointers. Named as `contracts: [ADR-AI]` in the front matter of plan-intake, plan-decide and
plan-value. Not yet registered; no gate run (the contract's own rule 3).

## Why its value is high

Every agent starts cold on a small model. Tests are the largest cost of a session and a mutating git command by an agent cannot be undone by
the user. One short contract bounds what every agent spends its calls on, before any plan or brief.

## The user's words (2026-10-16), the material

- Very minimal, at most 100 lines total; all agents read it at start, after a clear too; readable and actionable by haiku.
- Mentioned in the front matter of robots and skills as a contract. No links; 5 to 10 token sentences plus ADR shortnames, with and without
  numbers.
- Never run tests while working; postpone them to the end as a warning to the user when all is done; tests cost. Smaller tests may run
  directly; the raw Test-Automation and the like are the user's by sensible default.
- Find a smarter, shorter way to verify assumptions, or trust what the repository shows right now.
- Agents never do git. They may query git (expensive) or trust that working forward works, since all downstream is quality-controlled.
