# task007: body-sha Phase 0, the hash only on generated tracked files

Decided (Q10, go now): a body hash is required and autogenerated on generated, git-tracked files; an authored page never needs one, a
hand-added one is no finding and is never maintained. Today `file-meta.yml` kind `body-sha` selects `{ languages: [markdown] }` (line 24),
so every authored page is stamped and every ADR edit is a drift finding until Format-FileMeta runs. This change makes every later edit
cheaper and unblocks the ADR link cleanup (T027). C# edits need a fresh pwsh; the gates run in the background under the time safeguard.
