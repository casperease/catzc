# VS Code extensions: recommend the minimum, replace what cats tooling already does

The goal: an extension leaves the recommendations when cats tooling, a cats extension, or a generated setting does its job. Kept without
question: the 1-1 vendor language extensions (C#, Python, PowerShell, Go, Bicep, YAML, XML) and the known, fast formatters and linters that
cats has no parity for (Ruff, Prettier, markdownlint, cspell). The recommendations are generated by `New-VsCodeExtensions` from
`vscode-extensions.yml` plus each language's `vscode_extension` in `languages.yml`.
