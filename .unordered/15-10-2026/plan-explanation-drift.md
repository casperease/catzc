# Plan: close the code/ADR drift recorded in explanation docs, then drop the section

## Scope

82 docs under `docs/explanation/` carry a `## Where the code and the ADR differ` section. The section comes from the explanation template in
`.claude/drawio/STYLE.md:289` ("Only when drift exists …"), so every diagram wave adds more of them. Together they hold about 150 bullets.
With duplicates removed, that is **57 distinct drifts**, listed in the inventory below.

The plan has two goals:

1. **Correct every drift** by fixing the code or amending the ADR, whichever side is wrong, so that the two agree.
2. **Remove the section** from every explanation doc and from the template, so explanation reads as the present-tense account of how cats
   works (`ADR-PRIN-ONELIVE`: no "the code lags" notes in docs).

After the sections are removed, this file is the only record of the drift. Keep it until Phase 4 is closed.

## Legend

- **Fix** says which side changes. `code` means the code moves to match the ADR. `ADR` means the ADR is amended to match the code. `decide`
  means you choose (see [Open decisions](#open-decisions)).
- **Docs** lists the explanation docs that cite the drift, by stem (folder omitted). Their diagrams may show the drift as an ADR-only glyph
  (see Phase 3).
