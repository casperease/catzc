# Plan: ADR ↔ code drift found by the explanation articles

Written 2026-10-14 from the "Where the code and the ADR differ" sections of the 88 `docs/explanation/` articles (82 have one; raw extract:
`out/diagrams/wave-7/_drift_raw.md`; claim-level evidence with `file:line` in `out/diagrams/wave-7/**/*.verify.md`). Duplicates across
lenses are merged. Every item still open needs your call (solved items pruned 2026-10-15). Items marked "wave 9" come from the source-lens
slides' verify files under `docs/.assets/references/automation/` (2026-10-15).

Each item says what the ADR says, what the code does, and a **recommendation**:

- **Fix code**: the ADR states the intent, and the code (or a comment) should follow.
- **Fix ADR**: the code is the intended truth, so amend the ADR (present tense, ADR-PRIN-ONELIVE).
- **Decide**: either side is reasonable, or the item is a feature that isn't built yet.

When an ADR changes, the articles that list the item change in the same change: their drift section shrinks or goes. Items marked **PWSH**
touch ADRs that the ADR-PWSH split (`out/plan-adr-pwsh-split.md`, catzc-27) moves or renumbers, so do them after its P4 sweep, or with that
session.
